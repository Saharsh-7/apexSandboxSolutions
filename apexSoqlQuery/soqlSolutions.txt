📌 Unique SOQL Assignment Questions:

1. Get all Contacts where LastName is 'Smith'.
SELECT Id, LastName FROM Contact WHERE LastName = 'Smith'

2. List all Opportunities with StageName = 'Closed Won'.
SELECT Id, Name, StageName FROM Opportunity WHERE StageName = 'Closed Won'

3. Retrieve all Leads with Company name starting with 'A'.
SELECT Id, Name, Company FROM Lead WHERE Company LIKE 'A%'

4. Fetch all Users who are active.
SELECT Id, Name, Username FROM User WHERE IsActive = true

5. Get all Cases where Status is not 'Closed'.
SELECT Id, CaseNumber, Status FROM Case WHERE Status != 'Closed'

6. List all Accounts sorted by Name.
SELECT Id, Name FROM Account ORDER BY Name

7. Fetch top 5 Accounts using LIMIT.
SELECT Id, Name FROM Account ORDER BY CreatedDate DESC LIMIT 5

8. Find all Contacts with email containing 'gmail'.
SELECT Id, LastName, Email FROM Contact WHERE Email LIKE '%gmail%'

9. List all Opportunities created in the last 30 days.
SELECT Id, Name, CreatedDate FROM Opportunity WHERE CreatedDate = LAST_N_DAYS:30

10. Fetch all Account records.
SELECT Id, Name FROM Account

31. List Contacts whose Accounts are in the 'Banking' industry.
SELECT Id, LastName, Account.Name FROM Contact WHERE Account.Industry = 'Banking'

32. Get all Opportunities where Amount > 50000 and close date is next month.
SELECT Id, Name, Amount, CloseDate FROM Opportunity 
WHERE Amount > 50000 AND CloseDate = NEXT_MONTH

33. Retrieve all Contacts along with their Account Names.
SELECT Id, LastName, Account.Name FROM Contact

34. Fetch all Cases grouped by Priority using aggregate function.
SELECT Priority, COUNT(Id) totalCases FROM Case GROUP BY Priority

35. Find total Opportunity Amount grouped by AccountId.
SELECT AccountId, SUM(Amount) totalAmount FROM Opportunity GROUP BY AccountId

36. List all Leads created by current user using UserId.
SELECT Id, Name, Company FROM Lead WHERE CreatedById = :UserInfo.getUserId()

37. Get top 10 Opportunities by Amount using ORDER BY.
SELECT Id, Name, Amount FROM Opportunity 
WHERE Amount != NULL ORDER BY Amount DESC LIMIT 10

38. Find all Tasks that are overdue and not completed.
SELECT Id, Subject, ActivityDate, Status FROM Task 
WHERE Status != 'Completed' AND ActivityDate < TODAY

39. Fetch Accounts with null Industry field.
SELECT Id, Name, Industry FROM Account WHERE Industry = NULL

40. Fetch all Accounts with more than 5 Opportunities using subquery.
SELECT Id, Name, (SELECT Id FROM Opportunities) 
FROM Account 
WHERE Id IN (SELECT AccountId FROM Opportunity GROUP BY AccountId HAVING COUNT(Id) > 5)

71. Retrieve Opportunities with related Account and Owner names.
SELECT Id, Name, Account.Name, Owner.Name FROM Opportunity

72. List Contacts from Accounts that have no related Opportunities.
SELECT Id, LastName FROM Contact 
WHERE AccountId NOT IN (SELECT AccountId FROM Opportunity WHERE AccountId != NULL)

73. Find average Opportunity amount grouped by StageName.
SELECT StageName, AVG(Amount) averageAmount FROM Opportunity GROUP BY StageName

74. Use IN clause to get Leads with LeadSource in ('Web', 'Phone').
SELECT Id, Name, LeadSource FROM Lead WHERE LeadSource IN ('Web', 'Phone')

75. Fetch Accounts created this year and sort by CreatedDate DESC.
SELECT Id, Name, CreatedDate FROM Account 
WHERE CreatedDate = THIS_YEAR ORDER BY CreatedDate DESC

76. List Opportunities where the Account's Industry is not null.
SELECT Id, Name, Account.Industry FROM Opportunity WHERE Account.Industry != NULL

77. Count number of Contacts for each Account and display those with more than 5 Contacts.
SELECT AccountId, COUNT(Id) contactCount FROM Contact 
GROUP BY AccountId HAVING COUNT(Id) > 5

78. Fetch all Opportunities along with Parent Account and Owner's Email.
SELECT Id, Name, Account.Name, Owner.Email FROM Opportunity

79. List all child records (Contacts) for a parent Account in one query.
SELECT Id, Name, (SELECT Id, LastName FROM Contacts) FROM Account

80. Get all Accounts having more than 3 related Contacts using HAVING clause.
SELECT AccountId, COUNT(Id) contactCount FROM Contact 
GROUP BY AccountId HAVING COUNT(Id) > 3
